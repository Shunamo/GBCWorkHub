# GBCWorkHub 오로라 — 사용자 가이드

오로라 원격 PC에 접속하고, 작업 후 TFS 체크인을 업무기록으로 가져오는 앱입니다.

---

## 1. 처음 시작할 때 — 사용자 정보

앱을 처음 켜면 팝업이 뜹니다.

**소속** (예: 진료지원)과 **사용자명** (예: 김수현)을 입력합니다.

같이 보이는 값:

- **현재 IP** — 이 PC의 주소 (자동)
- **Windows 계정** — 로그인 계정 (자동, 예: `DESKTOP-xxx\SuhyunKim`)

사용자명이 갤러리·점유·업무기록 작성자에 쓰입니다. 소속은 업무기록 검색에 쓰여서, 파트장이 `진료지원`으로 팀원 기록을 한 번에 찾을 수 있습니다. IP·Windows 계정과 달라도 됩니다.

값을 넣고 **시작하기**를 누릅니다. 이름만 있던 PC는 다음에 앱을 켤 때 소속만 한 번 더 묻습니다. 나중에 마이페이지 이름 옆 연필에서 바꿀 수 있습니다. 화면에는 `김수현 진료지원`처럼 보입니다.

---

## 2. 접속

1. 사이트에서 **AURORA**를 고릅니다.
2. 비어 있는 PC를 고르고 접속합니다. 다른 사람이 점유한 PC는 막힙니다.
3. 원격 화면(mstsc)에서 평소처럼 작업합니다. 복사/붙여넣기도 그대로 쓰면 됩니다.
4. 원격 창을 닫으면 점유가 풀립니다.

---

## 3. TFS 가져오기

원격 작업을 끝내면 “이번 작업의 TFS 체크인을 가져올까요?”가 뜹니다.

- **가져오기** — 잠깐 원격에 다시 붙습니다. 정상입니다. 체크인 목록이 오면 업무기록에서 고릅니다.
- **나중에** — 지금은 닫고, 업무기록 → TFS 가져오기에서 같은 접속 구간을 고를 수 있습니다.

---

## 4. 클립보드에 `GBCWORKHUB`가 보이면

앱과 원격 PC가 잠깐 주고받는 문구입니다. 붙여넣기에 이 글이 나오면 잠시 기다리거나, 필요한 글을 다시 복사하면 됩니다. 일반 복사본은 앱이 지우지 않습니다.

---

## 5. 안 될 때

| 상황 | 확인 |
|------|------|
| 점유명 창이 또 뜸 | 지난번에 시작하기를 안 눌렀거나, 위 json을 지운 경우 |
| 다른 사람 이름으로 점유됨 | 그 PC를 쓰고 있는 것입니다. 끝날 때까지 기다립니다 |
| 접속이 안 됨 | 담당자에게 그 PC가 목록에 등록돼 있는지 확인 |
| 가져오기가 안 됨 | 가져오기 후 잠깐 뜨는 원격 창을 바로 닫지 마세요 |
